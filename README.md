# FlowPy

Build a flowchart, run it, and see the Python code it turns into. Made for complete beginners.

- Drag shapes (Set value, Input, Output, Decision, Loop while, Count loop) onto the `+` points.
- Press **Run**: shapes light up as they run, the matching Python line is highlighted, output and variable values show on the right.
- The whole program is saved (compressed) in the `?p=` URL parameter. **Copy link** shares it.

It is one static file (`index.html`), no build step.
